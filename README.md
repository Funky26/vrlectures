# VR Atom Builder – Interaktívne učenie chémie vo virtuálnej realite

**VR Atom Builder** je edukačná VR aplikácia zameraná na pochopenie **štruktúry atómu** pomocou interaktívnej tvorby atómov. Používateľ pridáva **protóny, neutróny a elektróny**, sleduje **stabilitu atómu** a vidí výsledok priamo zvýraznený v **periodickej tabuľke prvkov**.

Projekt je určený pre **Meta Quest (Quest 2 / Quest 3)** a je vhodný pre školy, študentov aj samoukov.


## Ako aplikácia funguje

- Počet **protónov** určuje chemický prvok  
- **Neutróny** ovplyvňujú stabilitu jadra  
- **Elektróny** sa porovnávajú s protónmi (neutrálny atóm)  
- Aktuálny prvok je automaticky **zvýraznený v periodickej tabuľke**  
- Stabilita atómu sa vyhodnocuje podľa základných fyzikálnych pravidiel  

Všetky zmeny sa aktualizujú **v reálnom čase**.


## Ovládanie a gameplay

- Ovládanie pomocou VR ovládačov  
- Tlačidlá na pridávanie a odoberanie častíc  
- Okamžitá spätná väzba v UI  
- Nevyžaduje sa predchádzajúca znalosť chémie  


## Inštalácia (Meta Quest)

### Požiadavky
- Meta Quest 2 alebo Meta Quest 3  
- Zapnutý **Developer Mode**  
- USB-C kábel  

### Postup inštalácie
1. Stiahni **APK súbor** (napr. z itch.io)
2. Zapni Developer Mode na headsete
3. Nainštaluj APK pomocou:
   - **Meta Quest Developer Hub** (odporúčané), alebo
   - príkazu:
     ```bash
     adb install nazov_aplikacie.apk
     ```
4. V headsete otvor:
   - **Library**
   - **Unknown Sources**
   - Spusť aplikáciu

Projekt je zameraný na **vzdelávanie** a **jednoduché pochopenie základov atómovej fyziky**. Nejde o plnú vedeckú simuláciu, ale o didaktický nástroj.
